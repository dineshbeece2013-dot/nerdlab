    What you learned

    • One container does one job. The app and its database are separate containers that talk to each other.
    • Containers find each other by name. Compose gives every service a name that works as its address.
    • A container forgets everything when it stops — unless you attach a volume to keep the data outside it.
    • Nothing is reachable from outside until you publish a port. Inside the stack is a private world.
