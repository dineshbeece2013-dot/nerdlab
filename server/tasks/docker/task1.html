Docker Task 1: Build & Run Container

In this lab exercise, you will create a custom Dockerfile for an Nginx web application and map port 8080.

Step 1: Write Dockerfile

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80

Step 2: Build & Run Docker Image

docker build -t my-devops-app:v1 .
docker run -d -p 8080:80 --name web-container my-devops-app:v1
