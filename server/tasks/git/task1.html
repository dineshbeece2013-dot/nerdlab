Git Level 1

Git Task 1: Basic Commit & Branching

In this lab exercise, you will practice fundamental Git operations including repository initialization, staging files, creating commits, and managing feature branches.

Step 1: Initialize Git Repository

Create a new folder and initialize Git:

mkdir devops-git-lab && cd devops-git-lab
git init

Step 2: Create a File & Stage Changes

Create a file named README.md and check status:

echo "# DevOps Learning Lab" > README.md
git add README.md
git status

Step 3: Commit Changes & Create Branch

Commit your staging changes and checkout a feature branch:

git commit -m "feat: initial commit"
git checkout -b feature/login-page
