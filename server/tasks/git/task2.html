Git: Undoing Things Safely

Why this is worth learning properly

Most people learn Git well enough to save their work, then freeze the first time they need to take something back. They copy the folder "just in case", paste code into a chat window, and hope.

Git has three different undos, and picking the wrong one is how work actually gets lost. They differ in one thing: how much they destroy. One throws away an edit you have not saved. One removes a save but keeps the work. One adds a new save that cancels an old one, changing nothing about the past.
