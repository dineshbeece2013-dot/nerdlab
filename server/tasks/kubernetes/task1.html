Kubernetes Task 1: Deploy Pods & Services

In this lab exercise, create a Kubernetes Deployment manifest and expose it via NodePort Service.

Step 1: Create deployment.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.21
        ports:
        - containerPort: 80

Step 2: Apply Manifest

kubectl apply -f deployment.yaml
kubectl get pods
