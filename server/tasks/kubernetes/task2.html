Kubernetes: Why Won’t It Start?

Reading what the cluster tells you

A Kubernetes file can be perfectly valid and still never run. The cluster accepts it, creates the pods, and then something goes wrong that only shows up in the pod’s status.

Learning the three or four statuses you will actually meet is most of troubleshooting. Each one names its own cause if you know how to read it: 

ImagePullBackOff   it cannot download the image you asked for
CrashLoopBackOff   it starts, dies, and is restarted, over and over
Running, not Ready the app is alive but says it cannot serve yet

Notice the third one. Running is not the same as working, and a pod can sit there looking healthy while receiving no traffic at all.
