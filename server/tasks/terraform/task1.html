Terraform: Infrastructure You Can Rebuild

What is Terraform?

Servers are usually created by clicking. Someone opens a cloud provider's website, picks a size, ticks some boxes, presses Create. It works, and it takes five minutes.

The trouble arrives months later. Nobody remembers which boxes were ticked. There is no list of what exists. If the server is lost, or a second identical one is needed for testing, somebody is reconstructing it from memory.

Terraform replaces the clicking with a file. You write down what should exist — three servers of this size, with these names — and Terraform makes reality match it. Run it again and it changes nothing, because reality already matches. The file becomes the record: readable, reviewable, and repeatable.

What you learned

  • You describe the result, not the steps. Terraform works out what to create, change or destroy.
  • Running it twice changes nothing. If reality already matches the file, there is no work to do.
  • Variables remove copy-paste. One value, named once, used everywhere.
  • Terraform remembers what it made. That record is how it tells "create a new one" from "change the existing one".
