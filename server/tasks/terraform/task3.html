Terraform: One Block, Many Servers

Copy-paste does not scale

Three environments, each with a web server and a worker, is six near-identical blocks. Six places to edit when anything changes, and six chances to miss one.

Terraform has two ways to build many things from one block. count makes a numbered set — copy 0, copy 1, copy 2 — which is right when the copies are interchangeable. for_each builds one per entry in a list of names, which is right when each one means something and has to stay itself.

The difference matters more than it looks, and this lab shows why by removing one from the middle.
