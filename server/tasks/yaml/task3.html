YAML in the Wild: A Build Pipeline

Where the shapes you learned actually turn up

You can write names and values, lists, and settings inside settings. Real files combine all three at once, several levels deep, and that is a different skill from knowing each piece.

The file you will build here is a CI workflow — the instructions a service like GitHub Actions follows every time somebody changes the code: check out the code, run the tests, and if they pass, deploy. It is one of the most common YAML files in the world, and it is nothing but lists of settings inside settings.

One old friend also reappears. YAML's habit of turning words into true or false is not limited to values — it can happen to a key, and this file has exactly the key it happens to.
